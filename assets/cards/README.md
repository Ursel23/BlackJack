# Cartas PNG de 21 BCN

La interfaz busca primero estas 53 imágenes:

- `spades-A.png` … `spades-K.png`
- `clubs-A.png` … `clubs-K.png`
- `hearts-A.png` … `hearts-K.png`
- `diamonds-A.png` … `diamonds-K.png`
- `back.png`

Todos los archivos deben vivir directamente en `assets/cards/`.

Si alguna imagen no existe, el frontend mantiene una carta de fallback generada con HTML/CSS para que el juego siga funcionando.

El ZIP generado a partir de las cuatro láminas ya respeta exactamente esta nomenclatura.
