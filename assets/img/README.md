# Fondo de Barcelona

Coloca aquí una imagen horizontal con licencia adecuada usando exactamente este nombre:

`barcelona-bg.jpg`

La web la utiliza como fondo muy desenfocado y oscuro. Si el archivo no existe, se conserva el fondo degradado actual.

Recomendación: una panorámica nocturna o de blue hour, con espacio negativo y sin texto. Conviene guardar la imagen localmente en el repositorio en lugar de enlazarla en caliente desde un banco de imágenes.
